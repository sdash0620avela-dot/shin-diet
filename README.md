# 慎の減量管理 v12 実用テスト版

毎日使いたくなるAIダイエットコーチアプリ。

## v12 の主な改善

- GitHub本体へ実使用テスト項目を統合
- 脂質・炭水化物・水分・空腹感・疲労感・体調・筋トレ時間を日付別保存
- 日本時間で日付がずれないローカル日付処理
- 設定を含むバックアップ書き出しと復元
- v11の既存データをそのまま継続利用

## v11 の改善

- Apple風のシンプルで高級感あるデザイン（iOSカラー・ガラス風タブバー）
- ホーム画面を見やすく再構成（AIコーチカードを最上部に配置）
- 今日の評価を100点満点で表示（リンググラフ付き）
- 昨日との比較（評価点・体重）
- 7日平均（体重・評価）
- 今週の体重変化
- 未来予測をグラフ化（実績＋予測ライン）
- モチベーションメッセージ追加
- 入力画面のクイック入力チップ・セクション整理
- カード表示アニメーション
- スマホ表示最適化（safe-area・タッチターゲット）

## 既存機能（維持）

- 日付ごと保存・読み込み
- 保存後に入力欄が消えない
- 過去日付の再編集
- 写真は撮影・ライブラリ選択両対応（プレビューのみ・保存しない）
- 体重グラフ、最近の記録、AIコーチ評価、週間レポート
- データ書き出し・全削除
- PWA対応（オフラインキャッシュ）
